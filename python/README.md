# Ailune Python package

The Python side contains the AI service, PyQt6 interface, GTK4 pet shell and the
Live2D model importer. See the repository root `README.md` for setup and usage.

Run modules with the checkout on `PYTHONPATH`:

```bash
PYTHONPATH=. python -m ailune.ui
PYTHONPATH=. python -m ailune.service
PYTHONPATH=. python -m ailune.pet
```
